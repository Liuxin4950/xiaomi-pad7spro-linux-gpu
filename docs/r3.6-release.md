# r3.6 发布候选与架构审查

日期：2026-11-11。交付标识 **r3.6-rc1**；正式版状态 **未完成**。用户要求的快速鼠标流畅度尚未通过，新 Termux 真实冷启动与干净 rootfs 的验收也未完成。不能以修改版本名替代这些验收。

## 交付范围

- 固定 `d55f1b7e575de0a7d2b03c5882d5e3d375d01a4f` 及子模块导出，按 sources.lock 顺序应用 X11 0001–0017；0015 保留 Surface 到达早于共享 state 的空值修复，0016 解除光标对主帧等待的依赖，0017 请求鼠标输入源无缓冲分发。
- 全新 native 对象构建 APK；同源构建签名校验 loader 和两个 CLI 包装入口。报告保留真实工具链、依赖和产物哈希；使用上游公开测试证书，不宣称可信的生产签名。没有再次安装。
- Linux 渲染组件复用已部署 r3.5 / WSI 0012；Writer 的未通过候选、软件自动回退、未经证实的节拍改写不纳入。
- Termux 入口参数化、缺失入口初始化、版本配套 loader、备份回退；修复 Clipman 的 TryExec，取消启动阶段重复的 adbd 重启。
- 当前状态、迁移指南、维护操作分为三个入口；重复的旧状态迁入 history，研发原始记录保留。

## 架构审查结论

| 边界 | 处理与结论 |
|---|---|
| Linux 渲染 / Android 显示 | GPU 应用仍经统一 gpu-run → sysvk/libhybris → 原厂 Mali；WSI/AHB/Present 与 X11 显示分层，没有更换厂商驱动 |
| 主帧 / 独立光标 | 光标事务可绕过主帧等待，同一迭代继续处理 root/copy；主帧许可、所有权 fence 和裁剪顺序仍受原约束 |
| 光标生命周期 | state/Surface/目标可晚到或失效；回归覆盖 null state、残留目标、几何/形状快照、隐藏和清理 |
| Android 输入 / 光标发布 | 无缓冲分发不保证蓝牙报告、调度和屏幕呈现都到 120；实测仍有长尾，尚无充分证据再改调度器 |
| 会话观察 / 清理 | ADB 观察失败保留会话；仅两次成功确认退出后才能收尾。取消重复 adbd 重启，未增加轮询解冻或服务禁用 |
| Termux / rootfs | HOME/PREFIX/rootfs 分离，安装器负责文件事务，launcher 负责现有 root chroot；仍有 OS4 特定前提，不声称任意 rootfs 支持 |
| 版本身份 | 源码锁、构建包、已安装包、各运行进程分别记录；builder 的 version-name 不再固定写 final |

本轮确认并修正的是可直接追溯的问题；不把调用层数、回调计数或上限设置当作性能证据。独立光标减少主帧绘制的已有样本不等于整机能耗降低。

## 正式发布尚缺

1. 用户已明确报告的快速蓝牙鼠标跳动消除，并验证目标流畅度；当前第二包未获认可，相对捕获也未获明确验收。
2. rc1 在用户安排的安全切换后，两端加载同一版本，整会话冷启动、休眠恢复和回退通过。
3. 新 Termux 保留 rootfs 的真实配置启动；干净设备/OS4 rootfs、keepcaps 补丁的完整复现路径另需补齐。
4. 拟公开二进制的对应源码/依赖通知整理；修改版 bionic 对应源码与再分发范围仍是 Linux 二进制发布缺口，详见 LICENSE-STATUS。
5. 若声称能效/120 FPS，必须有同条件功耗和实际显示验收。目前不作该声明。

当前代码仓库已推送；没有创建公开 Release 或 Git tag。上述门槛通过后才能冻结正式版，而不是重复生成一个带 final 名字的包。
