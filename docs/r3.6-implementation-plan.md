# r3.6 实现路线与可复现交付说明

更新日期：2026-11-25

本文把 r3.6 的实现边界、已落地代码、候选构建和后续优化固化为可执行文档。**版本号不替代运行证据**：Linux 桥接、X11 前端、独立 X server、Termux/rootfs 和实际应用进程分别验收。

## 1. 目标和非目标

目标是：在同一类 Xiaomi Pad 7S Pro / Android 17 / Mali-G925-Immortalis 设备上，新建或迁移 Debian arm64 chroot 后，使用 `run-gpu` 即可走真实 Mali 硬件路径；兼容的普通 Vulkan/Zink 客户端在继承全局环境时也走硬件路径；应用明确请求软件渲染时才允许软件路径。

不把以下内容伪装成已完成：任意机型/任意固件兼容、原厂 Mali 再分发、透明窗口所有组合、WebKit 端到端零拷贝、真实物理 120 FPS、整机功耗降低、干净设备从零安装、X11 APK 已切换。

## 2. 组件和代码入口

| 层 | 实现 | 验收方式 |
|---|---|---|
| 入口 | `scripts/run-gpu.sh`、`scripts/gpu-run.sh` | 参数透传、默认硬件、`--software` 显式选择 |
| 公共环境 | `scripts/gpu-env.sh`、`scripts/install-global-env.sh` | source 后 ICD/Zink/Mali 变量正确；profile 事务可回退 |
| Linux ICD | `src/`、`libhybris`、`sources.lock.json` | 独立前缀构建、manifest、`probe-vulkan` |
| WSI/Present | `src/probe-present.c`、`wsi` 锁定补丁 | swapchain、重建、BGRA、窗口呈现回归 |
| X11 输入/光标 | `patches/termux-x11/0015–0017` | 候选 APK 离线回归；安装和进程映射仍待用户安排 |
| Termux 接入 | `scripts/configure-termux.py`、`scripts/bootstrap-termux.sh` | 新 HOME/PREFIX/rootfs 参数化、备份、冲突拒绝 |
| 应用策略 | `gpu-run.sh` 的 Chromium/Electron/WebKit 路由 | 逐应用确认 renderer；不能用 doctor 代替画面验收 |

核心约束：不覆盖已映射库、不自动重启桌面/Termux:X11、不改 SELinux/系统服务、不因硬件失败静默退回 CPU。

## 3. 2026-11-25 已实现并验证

### 3.1 Linux r3.6 独立候选

使用当前锁定源码和补丁，由 `scripts/build.sh` 在 `aarch64` 新前缀完成 fresh build：

- 构建目录：`/opt/pad7spro-gpu-release-test/repository/build/r3.6-linux-20261125/`
- 候选前缀：`/opt/pad7spro-gpu-r36-20261125`
- 安装方式：`scripts/install.sh`，未覆盖现有 r3.5 前缀
- 构建输出包含固定 RUNPATH、Vulkan ICD、WSI implicit layer、AHB wrapper、`gpu-run`、`gpu-env`、`run-gpu`
- `gpu-run doctor` 通过；`run-gpu --headless probe` 报告 `Mali-G925-Immortalis`、`VULKAN_DEVICE_SUBMIT_READBACK_OK`
- `probe-present --motion` 通过 `VULKAN_SWAPCHAIN_RECREATE_PRESENT_OK`

这证明候选前缀可构建、可安装、可创建真实 Vulkan 设备并完成受控 Present 回归；不证明现有桌面应用已经切换到该前缀。

### 3.2 通用 GPU 入口

- `run-gpu 应用 参数`：默认硬件 `auto` 路由。
- `source gpu-env`：导出公共 ICD、Zink、HYBRIS 和 Mali 环境。
- `/etc/profile.d/90-pad-gpu.sh`：只在已明确安装 profile hook 的 chroot 中对新 Bash 会话生效；已有会话不会热更新。
- WebKit preload、Electron 参数、CC Switch 具体 renderer 不放进公共环境，避免跨框架污染。

### 3.3 透明度/闪烁问题的处理边界

透明度不是单一“开关”：必须同时满足应用 renderer 的 alpha、X11 visual/ARGB surface、预乘 alpha、WSI 图像格式、Present 合成和 Android 最终 Surface 的语义。当前 WSI 已固定 BGRA 字节契约和 GPU copy，但没有宣称所有透明 Electron/WebKit 窗口都正确。出现全黑、闪烁或异常显示时，按以下顺序隔离：

1. 记录应用 renderer 和窗口 visual/alpha；
2. 用不透明固定背景 A/B，区分透明合成问题和 GPU/WSI 问题；
3. 核对 `libsysvk`、WSI、Mali 线程和实际进程 maps；
4. 仅在最小复现下修正 premultiplied alpha/visual/Present 生命周期；
5. 以真实 CC Switch/Trae 内容画面验收，不能用探针替代。

## 4. 新 chroot 的标准流程

1. 准备同机型可见的 Android `/system`、`/vendor`、`/apex`、`/dev/mali0`、binderfs、X11 socket 和 root chroot。
2. 运行 `scripts/build.sh --prefix /opt/<独立前缀>`，再用 `scripts/install.sh` 安装；构建目录不能改名，因 RUNPATH/ICD/manifest 固定。
3. 先运行 `PREFIX/bin/gpu-run doctor`、`run-gpu --headless probe`、`gpu-run ahb`。
4. 验证通过后，使用 `activate-release.py` 预览并在独立备份目录中切换 `/usr/local/bin`；不覆盖生产入口。
5. 使用 `install-global-env.sh --apply --backup <新目录>` 为新 Bash 会话安装 profile hook；XFCE 需要重新正常启动才能继承，不能靠重复点击单实例应用热换库。
6. 按应用矩阵验证 CC Switch、Trae、Chromium、Writer、WebKitGTK 和普通 Vulkan；失败时保留硬件失败证据，不自动降级 CPU。

## 5. 后续优化顺序（带实现条件）

### P0：透明度和内容正确性

增加独立的 alpha/visual/预乘测试窗口和截图像素检查，覆盖不透明、半透明、全透明、窗口遮挡、resize、前后台恢复。实现位置优先在 WSI surface/swapchain 生命周期和应用路由，不在全局环境中强塞框架参数。任何修复必须证明没有破坏 BGRA 字节契约和普通窗口。

### P0：应用 renderer 兼容矩阵

为每个应用记录：启动参数、实际 renderer、GPU vendor/device、WSI/Present、窗口可见性、透明度模式、崩溃/黑屏。CC Switch 重点覆盖主界面、设置、弹窗、透明 overlay；Trae 覆盖 `vscode-file`、编辑器、菜单、中文输入。失败应用先做最小硬件路径修复，不改成 CPU。

### P1：部署复现

补齐干净 rootfs/OS4 keepcaps 的源码、构建和验证；将 Android 能力发现、挂载前提、UID/ADB 授权和后台限制写成检查项。bootstrap 只配置入口，不假设它能创建 rootfs 或替换 APK。

### P1：节拍、队列和能效

分别记录应用 rAF、WSI submit、X11 Copy、SurfaceFlinger content layer 和可证明的新内容；建立静止、小范围动画、滚动、输入、resize、前后台六类固定负载。只有同条件功耗和长时热稳定样本才能形成能效结论。

### P2：格式和零拷贝

只有在 profile 证明 copy/格式转换是主要热点时，才评估 AHB 格式协商、直接导入和局部 damage。先保留可回退的 GPU copy；禁止用未经验证的普通 blit 替代当前 BGRA 契约。

## 6. 正式 r3.6 门槛

当前 Linux 候选不等于正式 r3.6。正式发布仍需：X11 前端和独立 server 同版并由用户安全重启后确认映射；整会话冷启动、休眠恢复和回退；快速蓝牙鼠标验收；干净 rootfs/OS4 keepcaps；公开二进制 notices；真实应用透明度/内容正确性；如要声称 120 FPS 或省电，还需物理显示与同条件功耗证据。

证据文件：`evidence/r3.6-linux-candidate-20261125.json`、`evidence/r3.6-release-preparation-2026-11-11.json`。当前生产仍是 r3.5，候选切换由用户安排，不自动执行。
